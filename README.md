# 🍔 MenuVerse

Uma experiência gastronômica digital com design premium, animações interativas e apresentação visual de dar água na boca.

## ✨ Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS3
- Lucide React

## 🚀 Funcionalidades

- Design moderno e responsivo.
- Identidade visual premium em preto e dourado.
- Apresentação interativa de hambúrguer com camadas individuais.
- Animações e efeitos visuais.
- Navegação entre seções do cardápio.

## 💻 Como executar

```bash
npm install
npm run dev
```

## 📦 Build de produção

```bash
npm run build
```
